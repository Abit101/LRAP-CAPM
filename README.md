# LRAP-CAPM
A machine learning system based on the Capital Asset Pricing Model (CAPM) that can determine if certain stocks are over or undervalued, and the risk level of these stocks relative to the market index. 
CAPM is a powerful tool in finance due to its intuitive and easy-to-apply nature.
This project use it to estimate coefficients, determine valuation accuracy, and find which stock promises the best risk-return relationship.
